Windows 专用的标签设计与热敏打印工具。用毫米为单位可视化设计标签，直连打印机（热敏标签机优先走原始指令），模板以 JSON 保存、可复用与分发。

**个人自用程序，仅供参考**，不保证适用于你的打印机与使用场景。

## 安装

- **不需要管理员权限，不弹 UAC**（per-user 安装），装到 `%LOCALAPPDATA%\LabelDesk`
- 需要 WebView2 Runtime：Windows 11 自带；Windows 10 多数已随 Edge 安装
- 卸载后 `data\` 目录会保留，模板不会丢

## 这个版本有什么

### 速打小窗

在表格里挑机器的同时打标签，不用在表格和打印窗口之间来回切。

模式栏点「小窗」收成一条**顶置无边框小窗**，只留四样东西：模板、粘贴框、打印、切回完整窗口。

用法三步：表格里 `Ctrl+C` 一行 → 小窗 `Ctrl+V` → `Enter` 出纸。

```
┌──────────────────────────────────────┐
│ 🖨 速打                    ⛶    ✕   │  ← 按住这条任意处可拖动
├──────────────────────────────────────┤
│ [笔记本标签 ▾]         Deli DL-888D… │
│ ┌──────────────────────────────────┐ │
│ │ 粘贴表格里的一行，按 Enter 打印   │ │
│ └──────────────────────────────────┘ │
│ 3 项已识别                   [ 打印 ] │
└──────────────────────────────────────┘
```

细节：

- **顶置**：始终浮在表格上面，粘贴不用切窗口
- **拖动**：按住顶部那条的任意位置（含图标与文字）
- **关闭**：与关闭完整窗口一致 —— **销毁界面释放内存**，程序留在托盘
- **记住形态**：这次用小窗，完全退出后重新打开也直接回到小窗
- **打完自动清空并保持焦点**，可以连着打下一台
- `Esc` 切回完整窗口

### 托盘驻留

关闭窗口**不会退出程序，也不是把窗口藏起来**，而是彻底销毁窗口：

| | 关闭窗口后 | 从托盘打开 |
| --- | --- | --- |
| 窗口 | 已销毁 | 重新创建 |
| WebView2 渲染进程 | 退出（内存释放） | 重新拉起 |
| 进程与托盘图标 | 保留 | 复用 |

托盘图标留在系统托盘，点一下就能回来，会恢复上次用的窗口形态。想彻底退出：右键托盘图标选「退出」。

> Windows 11 默认把新托盘图标收进「显示隐藏的图标」折叠区（任务栏的 `^`），可以拖出来固定。

### 开机启动（默认开启）

首次运行自动登记，之后可在右上角**「设置」**里开关 —— 关掉就不会再自动打开。

登记在 `HKCU\...\CurrentVersion\Run`，只对当前用户生效，不需要管理员权限。

### 数据统一放安装目录

模板与配置都在 `<安装目录>\data\`，便于整体备份和搬迁：

```
%LOCALAPPDATA%\LabelDesk\data\
  ├── config.json               # 上次用的模板/打印机、开机启动开关、窗口形态
  └── layouts\*.ldl.json        # 标签模板
```

设置页有「**打开目录**」和「**备份到…**」。早期版本放在 `%APPDATA%\com.labeldesk.app` 的数据会**自动迁移**过来。

## 其它能力

- **一键打标签**：操作员从表格复制一行（型号 / 入库时间 / 配置 / 价格 / 回收人 / 序列号），粘贴即出标签
- **可视化设计**：拖拽、八向缩放、旋转、网格吸附、框选多选、对齐分布、图层、撤销重做
- **毫米为准**：几何以毫米描述，按打印机 DPI 换算，203/300/600dpi 下物理尺寸一致
- **两类打印通路**：Windows 驱动（兼容任何打印机）／原始指令（TSPL、ESC/POS、ZPL）
- **条码**：Code 128 / 39 / EAN-13 / EAN-8 / UPC-A / ITF-14，以及 QR 二维码（支持中文）
- **变量占位符**：内容里写 `{{型号}}`，一套版式反复用

## 已知限制

- 仅在 **Deli DL-888D**（203dpi，TSPL 指令集）上做过真机验证；ESC/POS 与 ZPL 两条通路只做了指令流结构测试，**没有真机验证过**
- **QR 二维码版本 > 6 不可用**：版本 7 及以上的数据区编码有 bug，功能图案/版本信息/校正图案/码字流/RS 纠错都已用独立参考实现逐字节核对一致，问题收窄到「矩阵位放置」但未找到根因。当前按纠错等级收敛容量并给出告警
- 走驱动打印时，标签尺寸依赖打印机驱动里的纸张设置（原始指令通路不受影响）
- 仅 Windows；无自动更新、无遥测
- 打印位置可能有几毫米偏差（标签机机械定位特性），程序内提供「定位补偿」可调

**使用前请先用少量标签纸试打确认效果。**
